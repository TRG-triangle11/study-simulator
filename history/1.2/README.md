# 自习模拟器（Study Simulator）

一个由学生创建的自习专注模拟器，用沉浸式的电子时钟，帮助你更好地进入专注状态。

## 功能特性

- **四大专注模式自由切换**：
  - **实时时钟**：大字沉浸式电子钟，支持日期与星期显示。
  - **番茄工作法（Pomodoro）**：支持自定义专注与小憩时长（默认 25+5 分钟），带空灵提示音。
  - **正向自习计时（Stopwatch）**：累计本次自习专注时长，结束自动归档入学习记录。
  - **目标倒数日（Target Countdown）**：自定义考试或纪念日（如考研/期末），实时倒数天/时/分。
- **禅意极简模式 (Zen Mode)**：一键隐藏所有侧边待办、顶部切换栏与按钮，纯粹沉浸于时间与背景；在顶部靠近边缘时自动优雅浮现「✕ 退出禅意」胶囊按钮。
- **多种内置字体**：全量内置自托管字体（无论系统是否安装均可完美渲染）：
  - 现代无衬线（HarmonyOS Sans SC 鸿蒙黑体）
  - 未来科技（Orbitron）
  - 古典衬线（Cinzel）
  - 七段数码（DSEG7）
- **Web Audio 纯原生禅意铃声**：倒计时结束自动播放空灵五度和弦提示音，无音频文件依赖，完全离线运行。
- **每日专注寄语（Quotes）**：时钟下方优雅展示自习励志语录，支持点击文字直接平滑切换下一句，可在日期待办首项自由开关。
- **双侧随手待办清单**：鼠标靠近屏幕左上角或右上角自动浮现，独立记录待办事项。
- **多音轨白噪音混音台**：右下角「🎧 氛围音效」支持原生合成窗前雨滴（真实水滴落地清脆滴水声）、壁炉、自习室、夏夜清风、远方潮汐，任意滑动自由混音，无音频文件依赖。
- **暗黑毛玻璃风格目标日期选择器**：彻底告别浏览器原生复古白底控件，完美适配暗黑主题与 HarmonyOS Sans SC 字体，内置 `+7天`、`+30天`、`百天冲刺`、`+1年` 一键跳转快捷胶囊。
- **沉浸式自习窗景壁纸体系**：
  - 窗前自习书桌系列（雨天 / 晴天 / 黄昏 / 现代高楼夜景 × 动漫美学 / 真实质感）
  - 自然的田野（晴空白天 / 璀璨星夜）与高楼俯瞰城市天际线
  - 无缝紧随的「＋ 自定义壁纸」上传入口，安全永久持久化于本地数据库（IndexedDB）。
- **动态氛围粒子系统（支持雨速与密度自定义）**：
  - Canvas 沉浸式轻量渲染，支持细雨划过、静谧雪花、深夜微尘与夏夜萤火
  - 「细雨」专属支持 **雨速微调（1~5档，默认舒缓柔和，避免视觉晃眼干扰专注）** 与 **雨滴密集度（1~5档，从零星微雨到密雨倾盆）**，后台自动休眠节电。
- **设置面板沉浸交互与 60 天打卡热力图**：
  - 选项卡（外观、专注、待办、统计）固定置顶，滑动时仅内容区平滑滚动
  - 统计栏目纵向一屏自适应展示，免上下滚动
  - GitHub 风格绿格打卡热力图，记录每日专注时长，激励习惯养成。
- **隐形交互感知设计**：
  - 顶部模式栏平时完全隐藏，鼠标滑向屏幕顶部自动滑出，切换模式后轻巧淡出；
  - 禅意模式下顶部「退出禅意」胶囊鼠标靠近即现；
  - 底部全屏按钮靠近浮现；
  - 左右侧待办靠近展开。
- **全键盘快捷键支持**：
  - `空格键`：开始 / 暂停计时
  - `Z`：进入 / 退出禅意极简模式
  - `F`：进入 / 退出全屏沉浸
  - `1 / 2 / 3 / 4`：快速在时钟、番茄钟、正计时、倒数日之间切换
  - `Esc`：关闭设置浮窗 / 退出禅意模式

## 使用方式

直接双击打开 `index.html` 即可使用，无需联网、无需配置任何服务器或安装依赖。

## 目录结构

├── sound.js              # Web Audio API 原生合成禅意铃声音效
├── ambient.js            # Web Audio API 原生程序化多音轨白噪音混音引擎（含真实仿真水滴滴水算法）
├── particles.js          # Canvas 动态微动粒子氛围系统（雨/雪/尘/萤火）

## 技术说明

- 纯原生 HTML5 / CSS3 / JavaScript 实现，单机运行，零外部网络依赖
- 本地存储分层：设置与轻量待办采用 `localStorage`，大图片壁纸与专注历史采用 `IndexedDB`
- 遵循完全离线优先原则，跨电脑、跨设备显示效果绝对一致
