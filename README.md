# 自习模拟器（Study Simulator）· v1.9.2

一个由学生创建的自习专注模拟器，用沉浸式的电子时钟帮助你进入专注状态。纯原生 HTML / CSS / JavaScript，零外部依赖、零网络请求。

> 历史版本 **v1.2** 的完整快照存放于 `history/1.2/`，可直接作为独立副本运行。当前根目录为 **v1.9.2**。

## 功能特性

- **三种模式**：实时时钟、番茄钟（自定义专注/休息时长）、正计时（从 0 开始累计专注时长，可暂停 / 继续 / 重置，离开页面自动归档到统计）。**主界面大时钟在任何模式下都常驻**；日期下方可选显示一行「距离 高考 还有287天」的目标倒数，只按自然日计算，相关设置集中在「设置 → 📅 日期待办 → 目标倒计时」。
- **禅意极简模式**：隐藏侧边待办、顶部栏与控制按钮；桌面端鼠标靠近顶部浮现退出胶囊，触摸端常显。
- **离线字体**：HarmonyOS Sans SC、DSEG7 Classic、Space Mono、IBM Plex Mono、Outfit 共 5 套自托管字体，全部 SIL OFL 许可，不依赖网络或系统字体；切换前统一预加载，避免字形闪烁。
- **每日寄语**：114 条简短的中外名句，居中显示于时钟下方，点击可换下一句，可在设置中关闭。
- **窗户雨滴特效**：基于开源项目 [raindrop-fx](https://github.com/SardineFish/raindrop-fx)（MIT）的 WebGL2 实时雨滴，大颗水珠带真实折射与下滑拖尾，像窗外在下雨；与细雨、飘雪等并列在「设置 → 🎨 外观时钟 → 屏幕效果」，由「屏幕动态效果」总开关统一控制。
- **PWA 可安装**：带 manifest 与 Service Worker，可「添加到主屏幕」独立运行、断网可用；已适配 iOS 的 `apple-mobile-web-app-*` 与刘海安全区。
- **设置搜索**：搜索框位于面板标题行（「设置」右侧），支持中文、全拼（`ziti`）、首字母（`sjzt`）与跳字模糊匹配；结果以浮层列表呈现，点击后自动切到对应分类、展开折叠分组、滚动到位并闪三下描边。
- **Web Audio 原生合成**：禅意提示音与 5 轨白噪音（雨/壁炉/自习室/夏夜/潮汐）均无需音频文件，支持主音量与分轨混音。
- **壁纸体系**：书桌 / 田野 / 城市窗景，支持上传自定义壁纸（自动压缩为 WebP/JPEG Blob 存入 IndexedDB）。
- **粒子氛围**：细雨、飘雪、微尘、萤火；细雨可微调速度与密度，适配高分屏与「减少动态效果」偏好。
- **双侧待办**：桌面端鼠标感应展开，触摸端点击边缘展开；回车快速添加。
- **统计与热力图**：今日专注、累计番茄、已完成待办，以及近 60 天按周对齐的打卡热力图。
- **全键盘操作**：`空格` 启停当前计时、`Z` 禅意、`F` 全屏、`1` 时钟 / `2` 番茄钟 / `3` 正计时、`Esc` 关闭浮窗 / 退出禅意。

## 安装到手机主屏（PWA）

需要先通过 http(s) 访问（本地可用 `python -m http.server 8000`，或部署到任意静态托管）；双击 `index.html` 的 `file://` 方式浏览器不支持 Service Worker，但功能本身照常可用。

**iPhone / iPad（Safari）**
1. 用 Safari 打开页面
2. 点底部「分享」→「添加到主屏幕」
3. 桌面出现时钟图标，点开即全屏运行（无地址栏），首次打开后即可离线使用

**Android（Chrome / Edge）**
1. 打开页面，右上角菜单 →「安装应用」或「添加到主屏幕」
2. 桌面图标启动后为独立窗口

**桌面 Chrome / Edge**：地址栏右侧出现「安装」图标，点击即可像本地应用一样启动。

## 使用方式

**推荐：通过本地静态服务器打开**（可确保 IndexedDB 与自托管字体在所有浏览器中正常工作）：

```bash
cd study-simulator
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

直接双击 `index.html`（`file://`）在部分浏览器中仍可使用，但存在以下限制：

- IndexedDB 可能被浏览器拒绝（Firefox 会抛 `SecurityError`，Chrome 的 `file://` origin 为 `null`），此时自定义壁纸与专注统计**仅在本会话内有效**，设置面板会显示降级提示；
- 自托管 `@font-face` 可能因 `file://` 的跨域策略回退到系统字体。

所有数据保存在本机浏览器（localStorage + IndexedDB），**不会跨设备同步**，也不会上传到任何服务器。

## 技术说明与已知限制

- 本地存储分层：设置 / 待办 / 计时状态用 `localStorage`，壁纸与专注历史用 `IndexedDB`；专注记录先入待写队列再落库，避免刷新丢失。
- 保留传统 `<script>` 加载（而非 ES Modules），以维持 `file://` 双击可用的能力；若后续需要模块化，应打包为单文件而非直接改用 module。
- 番茄钟与正计时均按墙钟时间计时；番茄钟在页面关闭期间若阶段到期，下次打开会补结算并归档一次，正计时在离开页面时自动暂停并归档增量、回来后可点「继续计时」；目标倒数按本地自然日计算，跨零点由心跳自动更新。
- 字体全部采用 **SIL Open Font License 1.1**，随项目自托管、无网络请求：HarmonyOS Sans SC（华为）、DSEG7 Modern（keshikan）、Share Tech Mono / Space Mono / IBM Plex Mono / Roboto Mono / Outfit（Google Fonts，经 Fontsource 打包为 woff2）。
- 未做实机浏览器自动化验证；`file://` 下的 IndexedDB 与字体行为因浏览器而异，请以本地服务器方式使用。
