# 自习模拟器（Study Simulator）· v1.3.2

一个由学生创建的自习专注模拟器，用沉浸式的电子时钟帮助你进入专注状态。纯原生 HTML / CSS / JavaScript，零外部依赖、零网络请求。

> 历史版本 **v1.2** 的完整快照存放于 `history/1.2/`，可直接作为独立副本运行。当前根目录为 **v1.3.2**。

## 功能特性

- **三大模式**：实时时钟、番茄钟（自定义专注/休息时长）、倒数日。主界面常驻一行「距离 高考 还有287天」的目标倒数，只按自然日计算、不显示时分；切到倒数日模式时该行文字放大居中，不再出现大号数字时钟。
- **禅意极简模式**：隐藏侧边待办、顶部栏与控制按钮；桌面端鼠标靠近顶部浮现退出胶囊，触摸端常显。
- **离线字体**：HarmonyOS Sans SC、DSEG7 Modern、Share Tech Mono、Space Mono、IBM Plex Mono、Roboto Mono、Outfit 共 7 套自托管字体，全部 SIL OFL 许可，不依赖网络或系统字体。
- **Web Audio 原生合成**：禅意提示音与 5 轨白噪音（雨/壁炉/自习室/夏夜/潮汐）均无需音频文件，支持主音量与分轨混音。
- **壁纸体系**：书桌 / 田野 / 城市窗景，支持上传自定义壁纸（自动压缩为 WebP/JPEG Blob 存入 IndexedDB）。
- **粒子氛围**：细雨、飘雪、微尘、萤火；细雨可微调速度与密度，适配高分屏与「减少动态效果」偏好。
- **双侧待办**：桌面端鼠标感应展开，触摸端点击边缘展开；回车快速添加。
- **统计与热力图**：今日专注、累计番茄、已完成待办，以及近 60 天按周对齐的打卡热力图。
- **全键盘操作**：`空格` 启停番茄钟、`Z` 禅意、`F` 全屏、`1~3` 切换模式、`Esc` 关闭浮窗 / 退出禅意。

## 使用方式

**推荐：通过本地静态服务器打开**（可确保 IndexedDB 与自托管字体在所有浏览器中正常工作）：

```bash
cd study-simulator
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

直接双击 `index.html`（`file://`）在部分浏览器中仍可使用，但存在以下限制：

- IndexedDB 可能被浏览器拒绝（Firefox 会抛 `SecurityError`，Chrome 的 `file://` origin 为 `null`），此时自定义壁纸与专注统计**仅在本会话内有效**，设置面板会显示降级提示；
- 自托管 `@font-face` 可能因 `file://` 的跨域策略回退到系统字体。

所有数据保存在本机浏览器（localStorage + IndexedDB），**不会跨设备同步**，也不会上传到任何服务器。

### v1.3.0

**计时与数据可靠性**

1. 计时器改为 `Date.now()` 绝对时间戳 + 单一心跳，后台节流 / 系统休眠不再漂移；`visibilitychange` 立即校准。
2. 删除番茄钟/正计时各自的 `setInterval`，渲染统一由心跳按当前模式执行，消除跨模式数字错乱。
3. 倒数日正确显示「天:时:分」，分钟不再被秒样式隐藏；「显示秒数」开关在所有模式下一致生效。
4. 计时状态持久化到 localStorage，刷新或误关页面可恢复；专注记录经待写队列落库，关闭页面时自动归档。
5. 全部日期改用本地时区 `YYYY-MM-DD`，修复 UTC+8 凌晨记录归到前一天、默认目标日期少一天的问题；热力图改为 60 天并按周对齐。
6. 专注记录按**实际秒数**存储并兼容 v1.2 的分钟数据；跳过阶段不再计入完成轮数。

**稳定性与性能**

7. IndexedDB 打开带超时 / `onblocked` / 降级探测，初始化不再阻塞界面渲染。
8. 白噪音共用唯一 AudioContext；关闭总开关或音轨归零时真正销毁节点与定时器；修正海潮 LFO 负增益；水滴/噼啪声纳入轨道音量控制。
9. 雨丝按透明度分组描边（层次感生效），适配 `devicePixelRatio`，后台显式休眠。
10. 自定义壁纸压缩为 Blob、限制 20 MB、加载失败回退默认壁纸、删除前二次确认、缩略图懒加载。
11. 修复「每次打开设置都重复绑定字号监听器」的泄漏。

**交互与可访问性**

13. `Esc` 在输入框内同样生效；隐藏浮层退出 Tab 顺序；补充 `:focus-visible`、`aria-*` 与 `prefers-reduced-motion` 支持。
14. 新增「背景暗化程度」与「主音量」滑块（原先为无法调节的死配置）。

## 技术说明与已知限制

- 本地存储分层：设置 / 待办 / 计时状态用 `localStorage`，壁纸与专注历史用 `IndexedDB`；专注记录先入待写队列再落库，避免刷新丢失。
- 保留传统 `<script>` 加载（而非 ES Modules），以维持 `file://` 双击可用的能力；若后续需要模块化，应打包为单文件而非直接改用 module。
- 番茄钟按墙钟时间计时，页面关闭期间若阶段到期，下次打开会补结算并归档一次；目标倒数按本地自然日计算，跨零点由心跳自动更新。
- 字体全部采用 **SIL Open Font License 1.1**，随项目自托管、无网络请求：HarmonyOS Sans SC（华为）、DSEG7 Modern（keshikan）、Share Tech Mono / Space Mono / IBM Plex Mono / Roboto Mono / Outfit（Google Fonts，经 Fontsource 打包为 woff2）。
- 未做实机浏览器自动化验证；`file://` 下的 IndexedDB 与字体行为因浏览器而异，请以本地服务器方式使用。
