# 自习模拟器（Study Simulator）

一个由学生创建的自习专注模拟器，用沉浸式的电子时钟，帮助你更好地进入专注状态。

## 功能特性

- **沉浸式电子时钟**：页面中央的大字时钟，单击任意处即可打开设置浮窗
- **多种时间字体**：现代无衬线 / 未来科技 / 古典衬线 / 七段数码（DS-Digital 风格）
- **灵活的时间显示**：可调字号、可开关秒针、秒数样式支持「紧凑」与「等大」两种
- **翻页时钟框**：可选为时分秒各配一个仿真翻页小框
- **丰富的背景**：内置黑色及「教室 / 图书馆 / 深夜书桌 / 窗外风景」四类场景，每类分动漫与写实两种风格，并支持上传自定义背景
- **日期显示**：可开关年份、月日、星期，支持调整字号与字间距
- **待办事项**：页面左右两侧各有一块独立待办区，常驻显示今日待办，文字透明度可调
- **底部全屏按钮**：鼠标靠近页面底部自动浮现「全屏显示」，一键进入沉浸式全屏（ESC 退出）
- **设置记忆**：所有设置自动保存在本地，刷新后保留

## 使用方式

直接双击打开 `自习模拟器.html` 即可使用，无需安装任何依赖。

## 目录结构

```
study-simulator/
├── 自习模拟器.html       # 主程序（单文件自包含）
├── assets/               # 资源文件
│   ├── classroom_anime.jpg / classroom_real.jpg     # 教室背景（动漫 / 写实）
│   ├── library_anime.jpg / library_real.jpg         # 图书馆背景（动漫 / 写实）
│   ├── desk_anime.jpg / desk_real.jpg               # 深夜书桌背景（动漫 / 写实）
│   ├── window_anime.jpg / window_real.jpg           # 窗外风景背景（动漫 / 写实）
│   └── dseg7-classic-400-normal.woff2               # 七段数码字体
└── README.md             # 项目说明
```

## 技术说明

- 纯 HTML / CSS / JavaScript 实现，单文件自包含，无框架、无构建步骤
- 背景图与字体通过相对路径引用，需与 `assets/` 目录放在同一层级
- 设置与待办数据通过 `localStorage` 保存在浏览器本地
